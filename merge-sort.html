🧩 Merge Sort

Split the list in half again and again until each piece has one item (trivially sorted), then merge the pieces back together in order.

Everyday picture: two teachers each have a sorted pile of exam papers. To combine them, you only look at the top paper of each pile, take the smaller one, and repeat. No digging around — merging two sorted piles is quick. Merge sort just keeps splitting until the piles are tiny, then merges its way back up.

Watch it

The bright bars show the section currently being merged; the faded ones are waiting. Notice it makes writes (copying values back) instead of swaps.

How it works

  1. Divide: cut the list into two halves.
  2. Conquer: sort each half the same way (recursively), until a half has just one item.
  3. Merge: compare the front items of the two sorted halves; move the smaller one into the result; repeat until both halves are used up.

The list is halved about log₂ n times, and each level of merging touches all n items — hence n log n in total.

In code (JavaScript)

function mergeSort(a) {
  if (a.length <= 1) return a;
  const mid = a.length >> 1;
  const left = mergeSort(a.slice(0, mid));
  const right = mergeSort(a.slice(mid));
  const out = [];
  while (left.length && right.length)
    out.push(left[0] <= right[0] ? left.shift() : right.shift());
  return [...out, ...left, ...right];
}

Real life

🗃️ Sorting huge files
Data too big for memory is sorted in chunks, and the sorted chunks are merged — that's merge sort.
🐍 Real libraries
Python and Java's default object sorts (Timsort) are built on merging.
