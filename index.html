💡 About this project

DSA Visualised is a free, open-source site that explains data structures, searching and sorting with everyday pictures and live visualisations — the kind of explanation I wish I'd had when I started out.

It's plain HTML, CSS and JavaScript: no sign-ups, no ads, nothing to install. Every demo runs in your browser, so you can break things and try again as many times as you like.

I'm Amol M Joshi, a software engineer who builds web applications with Ruby on Rails. If you liked this, you're welcome to see what else I've built.
